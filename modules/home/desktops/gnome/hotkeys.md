# GNOME Hotkeys

This document lists the keyboard shortcuts configured for the GNOME desktop environment.

## Window Management

| Action | Shortcut |
|--------|----------|
| Close window | `Super+Q` |
| Maximize window | `Super+Up` |
| Unmaximize/Restore window | `Super+Down`, `Alt+F5` |
| Toggle maximize | `Alt+F10` |
| Minimize window | `Super+H` |
| Move window | `Alt+F7` |
| Resize window | `Alt+F8` |
| Window menu | `Alt+Space` |
| Hide all normal windows | `Super+D` |

## Application Switching

| Action | Shortcut |
|--------|----------|
| Switch applications | `Super+Tab`, `Alt+Tab` |
| Switch applications (reverse) | `Shift+Super+Tab`, `Shift+Alt+Tab` |

| Switch windows of current application (reverse) | `Shift+Super+\``, `Shift+Alt+\`` |
| Switch panels | `Ctrl+Alt+Tab` |
| Switch panels (reverse) | `Shift+Ctrl+Alt+Tab` |
| Cycle windows | `Alt+Escape` |
| Cycle windows (reverse) | `Shift+Alt+Escape` |

| Cycle group (reverse) | `Shift+Alt+F6` |

## Customizations

The following shortcuts override GNOME defaults (configured in `keybindings.nix`):

- **Close window:** `Super+Q` (default: `Alt+F4`)
- **Minimize window:** `Super+H` (default: disabled)
- **Open terminal:** `Super+T` (default: `Ctrl+Alt+T`, disabled)
- **Open web browser:** `Super+W` (custom binding)
- **Switch workspace left:** Added `Super+Alt+Left` (default: `Super+Page Up`, `Ctrl+Alt+Left`)
- **Switch workspace right:** Added `Super+Alt+Right` (default: `Super+Page Down`, `Ctrl+Alt+Right`)
- **Move window to workspace left:** Added `Super+Shift+Alt+Left` (default: `Super+Shift+Page Up`, `Ctrl+Shift+Alt+Left`)
- **Move window to workspace right:** Added `Super+Shift+Alt+Right` (default: `Super+Shift+Page Down`, `Ctrl+Shift+Alt+Right`)
- **Switch input source:** `Super+Space` (custom binding)
- **Switch input source (reverse):** `Shift+Super+Space` (custom binding)
- **Search (Search Light):** `Super+B` (extension binding)
