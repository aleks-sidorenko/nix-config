# Ghostty Hotkeys

This document lists the keyboard shortcuts configured for the Ghostty terminal emulator.

## Window Management

| Action | Shortcut |
|--------|----------|
| New window | `Ctrl+Shift+N` |
| Close window | `Alt+F4` |
| Close all windows | - |
| Toggle fullscreen | `Ctrl+Enter` |
| Quit application | `Ctrl+Shift+Q` |

## Tab Management

| Action | Shortcut |
|--------|----------|
| New tab | `Ctrl+Shift+T` |
| Close tab/surface | `Ctrl+Shift+W` |
| Previous tab | `Ctrl+Shift+Tab`, `Ctrl+Shift+Left`, `Ctrl+Page Up` |
| Next tab | `Ctrl+Tab`, `Ctrl+Shift+Right`, `Ctrl+Page Down` |
| Go to tab 1-8 | `Alt+[1-8]` |
| Go to last tab | `Alt+9` |
| Move tab | - |

## Split Management

| Action | Shortcut |
|--------|----------|
| New split (right) | `Ctrl+Shift+O` |
| New split (down) | `Ctrl+Shift+E` |
| Focus previous split | `Ctrl+Super+[` |
| Focus next split | `Ctrl+Super+]` |
| Focus split up | `Ctrl+Alt+Up` |
| Focus split down | `Ctrl+Alt+Down` |
| Focus split left | `Ctrl+Alt+Left` |
| Focus split right | `Ctrl+Alt+Right` |
| Toggle split zoom | `Ctrl+Shift+Enter` |
| Resize split up | `Ctrl+Super+Shift+Up` |
| Resize split down | `Ctrl+Super+Shift+Down` |
| Resize split left | `Ctrl+Super+Shift+Left` |
| Resize split right | `Ctrl+Super+Shift+Right` |
| Equalize splits | `Ctrl+Super+Shift+=` |

## Copy & Paste

| Action | Shortcut |
|--------|----------|
| Copy | `Ctrl+Shift+C` |
| Paste | `Ctrl+Shift+V` |
| Paste from selection | `Shift+Insert` |

## Text Navigation

| Action | Shortcut |
|--------|----------|
| Scroll to top | `Shift+Home` |
| Scroll to bottom | `Shift+End` |
| Scroll page up | `Shift+Page Up` |
| Scroll page down | `Shift+Page Down` |
| Jump to previous prompt | `Ctrl+Shift+Page Up` |
| Jump to next prompt | `Ctrl+Shift+Page Down` |
| Clear screen | - |

## Font Size

| Action | Shortcut |
|--------|----------|
| Increase font size | `Ctrl++`/`Ctrl+=` |
| Decrease font size | `Ctrl+-` |
| Reset font size | `Ctrl+0` |

## Configuration

| Action | Shortcut |
|--------|----------|
| Open config | `Ctrl+,` |
| Reload config | `Ctrl+Shift+,` |

## Inspector

| Action | Shortcut |
|--------|----------|
| Toggle inspector | `Ctrl+Shift+I` |

## Scrollback

| Action | Shortcut |
|--------|----------|
| Write scrollback to file (paste) | `Ctrl+Shift+J` |
| Write scrollback to file (open) | `Ctrl+Shift+Alt+J` |

## AI

| Action | Shortcut |
|--------|----------|
| Claude code | `Shift+Enter` |
